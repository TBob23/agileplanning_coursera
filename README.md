# QA-Bot: Generativer Wissensassistent für die Qualitätssicherung (MVP)

Abschlussprojekt Agile Planning (Coursera).

Ein interner Wissensassistent (LLM + RAG), der Fragen zu Prüfanweisungen, Arbeitsanweisungen und FMEA-Dokumenten beantwortet und dabei jede Antwort mit der Quelle belegt.

## Projektstruktur
- Kanban-Board: siehe Reiter "Projects"
- User Stories: siehe Issues, angelegt über `.github/ISSUE_TEMPLATE/user-story.md`
- Sprint 1: Milestone "Sprint 1: MVP Suche und Quellenangabe" (20.10. bis 31.10.2026)
- Sprint 2 (geplant): Milestone "Sprint 2: Feedback und Sicherheit"

## Labels
| Label | Zweck |
|---|---|
| `product-backlog` | Noch nicht eingeplant |
| `sprint-backlog` | Im aktuellen Sprint |
| `feature` | Neue Funktion |
| `security` | Sicherheit / Datenschutz |
| `documentation` | Dokumentation |
| `technical-debt` | Technische Schuld |

## Schätzung
Story Points nach Fibonacci (1, 2, 3, 5, 8). Sprint 1: 21 SP, Product Backlog: 16 SP.
